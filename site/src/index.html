How it works

  1. Download the zip above. It contains everything — no binaries, no secrets.
  2. Run the guided setup (~30 min, your own free accounts: Vercel, Supabase, Telegram, cron-job.org, optional Slack).
  3. Get your messages — daily 07:00 + 20:00, Saturday 08:00 + 15:00 America/Edmonton.

What you need

  • Canvas account where you can create an access token
  • Free accounts: Vercel, Supabase, Telegram, cron-job.org, (optional) Slack
  • ~30 minutes · $0/month

Privacy

It runs entirely in your own accounts. Nothing is sent to us. This site sets no cookies and has no analytics or trackers. The Canvas token is read-only and never leaves your deployment.

Setup guide

  1. Unzip, then uv sync
  2. uv run canvasbuddy setup — validates Canvas, Telegram via getUpdates, Slack test, Supabase pooler, timezone + slots, writes .env + vercel.env, runs migrations + first sync
  3. Deploy: npm i -g vercel; vercel login; vercel link; vercel env import from vercel.env; vercel --prod
  4. Set Telegram webhook: curl api.telegram.org/botTOKEN/setWebhook -d url=PROJECT.vercel.app/api/telegram -d secret_token=WEBHOOK_SECRET
  5. Create cron-job.org job: GET PROJECT.vercel.app/api/cron every 15 min, header Authorization: Bearer CRON_SECRET
  6. Send /testnotify review to your bot. Full guide ships in the zip as SETUP.md.

FAQ

Will it work with my school? Needs Canvas + token creation allowed. Check your school's policy. UAlberta Canvas works.

Does it cost anything? No — Vercel Hobby, Supabase free, cron-job.org free, Slack webhook free.

Can it submit or change anything? No — read-only.

How do I update? Re-download, keep your .env.

Can I change the times? Yes — env vars DIGEST_SLOT etc.

Known limits? One person per deployment. Others self-host their own copy.
